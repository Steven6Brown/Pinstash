# Pinstash — Brand Guide

**Working tagline (proposed):** Pin it. Stash it. Keep it yours.

## The mark
A gold map pin with a keyhole cutout over water ripples: a private spot, locked away and kept yours.

## Files
| File | Use |
|---|---|
| `pinstash-app-icon.svg` / `.png` | App Store / home screen icon. 1024×1024, opaque, square (the system applies the rounded mask). |
| `pinstash-mark-on-light.svg` / `.png` | Transparent mark for light backgrounds. |
| `pinstash-mark-on-dark.svg` / `.png` | Transparent mark for dark backgrounds. |
| `pinstash-wordmark-on-light.svg` / `.png` | Mark + name + tagline for light backgrounds. |
| `pinstash-wordmark-on-dark.svg` / `.png` | Mark + name + tagline for dark backgrounds. |

## Palette
| Name | Hex | Use |
|---|---|---|
| Deep Water | `#0B3C49` | Icon field, text, dark surfaces |
| Gold | `#FFB703` | Pin, accent, key actions |
| Ripple | `#5CC8E8` | Water rings, accents on dark |
| Sand | `#FFF4D6` | Light surfaces |

## Type
Headings and numbers: SF Pro Rounded (bold). Body: SF Pro (system). The wordmark SVGs reference these fonts by name, so **convert the text to outlines in a vector editor before using a wordmark in print or on the web**, otherwise it will fall back to another font on machines without them.

## Voice
Quiet and discreet, like a fishing buddy who keeps a secret. Plain words. Never imply anything is shared or uploaded.

## Name check
On 2026-10-14 a search of the US App Store found no app titled exactly "Pinstash". This is not a trademark search and not a guarantee the name will be accepted: check App Store Connect name availability and run a USPTO search before committing. Alternates considered: Spotbook, Hushspot.

## Icon rules
- Keep the mark inside the central ~80% of the icon canvas.
- No text on the icon.
- Check the icon at 60×60 pt and in dark, tinted and clear iOS appearances before submission.
